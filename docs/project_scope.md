# Final Year Project Scope

## Title
RAG-Based Personalized LLM Educational System with Weak-Topic Detection and Adaptive Learning

## Research contribution
The supplied feature-analysis document proposes an RAG-based personalized educational system that detects weaknesses, adapts question difficulty, verifies answers against retrieved sources, and promotes active learning through hints. The implementation in this repository turns that proposal into a manageable web application.

## Selected additions
- Performance dashboard
- Weak-topic detection + adaptive difficulty
- Personalized learning path + source-backed answers
